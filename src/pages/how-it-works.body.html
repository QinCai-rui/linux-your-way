How it works

What's going on?!

You don't really need to understand all of it.

The kernel

The software that talks to your hardware (CPU, memory, storage, etc). EVERY single system has one. Linus first wrote the Linux kernel back in 1991.

System utilities

The tools that handle files, networking, managing packages, and other userland stuff

Desktop environment (DE)

The visual desktop is your taskbar, window decorations, and file manager. There are lots to choose from

Applications

Firefox, LibreOffice, Steam, VSCode. Most things you already use have Linux versions or good alternatives.

Try it yourself

A real Linux machine, in your browser

WebVM uses WebAssembly to run an actual Linux system inside your browser. You can type commands, open files, browse around. It can't touch your real computer.
