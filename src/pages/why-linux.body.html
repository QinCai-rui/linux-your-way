Why Linux

Why Linux is better :)

It doesn't spy on you

Windows sends a lot of telemetry back to Microsoft. macOS does too, and it ties you to Apple's ecosystem. Linux doesn't phone home, because there's no one to send it to.

You pick when things change

Windows decides when to restart your computer for updates. macOS does too. On Linux, you update when you want to, and your computer never reboots without YOUR permission.

Change how it looks

Don't like how things look? Change it. Want a tiling window manager like hyprland? Use it. Want to make it look like Windows? Sure.

"Outdated" hardware works fine

Most Linux distributions run well on computers that Windows 11 won't even install on. That 2013 Dell XPS (hi Deven)? It's still good, and hmm, perhaps you can even run a server on it ;)

"But isn't Linux hard?"

For everyday stuff, it works like Windows or macOS, but without the forced-update popups. You can use the terminal if you want it, but you don't need it.
