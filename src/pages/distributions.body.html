Distributions

There is no "one best version"

There are many Linux "distributions", each built around the Linux kernel. They look and feel different.

Fedora

More cutting-edge than almost anything else. You get new (but potentially unstable) software sooner

fedoraproject.org

Ubuntu

The most popular one for desktops. There are lots of tutorials. Good choice if you're not sure.

ubuntu.com

Linux Mint

Built on top of Ubuntu but with a more Windows-like layout (which I personally do not think is true)

linuxmint.com

Zorin OS

Designed to feel familiar if you're coming from Windows or macOS. It looks polished and runs well on older machines.

zorinos.com

You can test any of them from a USB stick (live installer) before installing anything.
