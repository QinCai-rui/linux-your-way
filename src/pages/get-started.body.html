Get started

How to try Linux
without breaking anything

Step 1

Pick a distro

Don't overthink it. Ubuntu or Mint are fine for most people, despite me hating Ubuntu personally. You can always switch later.

See the options

Step 2

Try it from a USB stick

Download the live ISO, put it on a USB drive, and boot from it. Everything stays in RAM, so nothing on disk changes

Step 3

Install if you like it

There is usually a live installer on the USB. It'll ask you a few questions and do the rest. It takes less time than Windows Updates.

More details

Before you start...

  • Back up anything you care about
  • Check that your wifi adapter works with Linux
  • Set aside an hour so you're not rushing
